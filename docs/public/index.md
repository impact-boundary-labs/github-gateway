# Public Docs

This is the public documentation entry point for **GitHub Gateway by Impact
Boundary Labs**.

## Public Structure

- [Homepage docs](homepage/01-overview.md): visitor-facing product overview,
  how the boundary works, security and scope explanation, live preview context,
  terminology, and support pages.
- [GitHub Gateway technical docs](githubrepo/index.md): the public technical
  documentation for GitHub Gateway Self-hosted 1.3, including setup,
  credentials, policy, intent format, security model, troubleshooting, and
  validation guidance.

## Documentation Boundary

Use `docs/public/` as the public documentation layer.

- `docs/public/homepage/` is the website-content layer.
- `docs/public/githubrepo/` is the technical product documentation layer.
- `docs/internal/` contains internal, historical, architectural, and working
  documents that are not the public contract.
